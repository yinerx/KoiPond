# KoiPond

一个字符网格风格的 macOS 池塘：锦鲤在深色水面下游动，点击水面会激起涟漪、撒下鱼饵，附近的锦鲤会游过来抢食。
可以作为**窗口**、**桌面壁纸**或**屏幕保护程序**运行，池塘里放什么、放多少、每只多大，都能在配置面板里调。

> 视觉灵感来自 [daoho.dev](https://www.daoho.dev/) 背景里的锦鲤动画，本项目的代码是独立实现的。

## 池塘里有什么

| 生物 | 特点 |
|---|---|
| 🐟 锦鲤 | 红白、大正三色、昭和三色、黄金、浅黄、丹顶六个品种，花纹每条都不一样；**唯一会吃鱼饵的生物** |
| 🪼 水母 | 伞盖一收一放地前进，触须拖在后面，会被涟漪推开 |
| 🐋 鲸鱼 | 又大又慢，隔一阵浮上来喷水 |
| 🦑 乌贼 | 喷射前进；受惊时喷墨逃走 |
| 🐢 乌龟 | 四鳍划水，定时浮上来换气 |
| 🦐 虾群 | 成群结队地游，受惊时弹尾散开 |
| 🍀 浮萍 | 漂在水面，被涟漪推散 |
| 🪷 睡莲 | 叶片会被涟漪晃动，有的开着花 |

## 安装

1. 在 [Releases](../../releases) 下载 `KoiPond-x.y.z.zip`，解压后把 **KoiPond.app** 拖进「应用程序」。
2. 这个 App 没有苹果开发者签名，第一次打开时 macOS 会拦截。任选一种方式放行：
   - 在 Finder 里**右键 KoiPond → 打开**，再点「打开」；或
   - 在终端执行：`xattr -dr com.apple.quarantine /Applications/KoiPond.app`

需要 macOS 14（Sonoma）或更新版本，Apple 芯片和 Intel 都支持。

## 使用

- **点击水面**：激起涟漪并撒下鱼饵，锦鲤会游过来吃。
- **鼠标快速划过**：附近的鱼会受惊逃开。
- **菜单栏的小鱼图标**：切换窗口 / 桌面壁纸、选择预设、打开配置、安装屏保、检查更新。
- **⌘,**：打开配置面板。

### 三种形态

| 形态 | 说明 |
|---|---|
| 窗口 | 普通窗口，可以全屏（⌃⌘F） |
| 桌面壁纸 | 铺在桌面图标下方，每块屏幕一个。点击桌面空白处会撒饵，点在其他窗口上不会触发。不需要任何系统权限 |
| 屏幕保护程序 | 配置面板 →「显示与更新」→「安装屏幕保护程序」，然后在系统设置里选择 KoiPond。屏保里会定时自动喂食。改了配置后点「同步当前配置到屏保」 |

窗口和桌面壁纸可以同时开；两个都关时，KoiPond 留在菜单栏里。

### 配置面板

- **全局设置**：主题、背景色、字符格大小、方块间隙、阴影、计数显示、模拟速度、涟漪强度和持续时间、每次撒饵数量、鱼饵上限和存在时间。
- **生物组**：可以添加任意多组。每组可以设置数量、**体型范围**（最小 / 最大，每只在其中随机；设成一样就是统一大小）、速度、深度范围，以及各自的专属参数（锦鲤的品种比例、好奇心、觅食范围、胆小程度；水母的脉动频率、触须长度、颜色；鲸鱼的喷水间隔；乌贼的喷射频率和喷墨；乌龟的换气间隔；虾群每群数量；浮萍每簇叶片数；睡莲开花概率）。
- **「可喂食」只对锦鲤可用**，其他生物不吃鱼饵。
- **预设**：锦鲤池、深海、混养、睡莲池。配置可以导出 / 导入 JSON，改动实时生效，下次启动自动恢复。

### 能耗

KoiPond 尽量少占资源，桌面壁纸模式尤其如此：

| 档位 | 平时 | 撒饵 / 涟漪 / 受惊时 | 渲染分辨率 | 默认用于 |
|---|---|---|---|---|
| 省电 | 6 帧 | 15 帧 | 低 | 低电量模式、Mac 过热时自动切换 |
| 均衡 | 12 帧 | 30 帧 | 低 | 桌面壁纸、屏保 |
| 流畅 | 60 帧 | 60 帧 | 原生 | 窗口 |

- 池塘被窗口完全挡住、显示器睡眠、锁屏、切换用户、屏保运行时，完全暂停。
- 只绘制有内容的字符格；画面没变化的帧直接跳过。
- 在「全局设置」打开「显示性能信息」，左下角会显示帧率、每帧耗时、绘制格数、渲染分辨率和内存占用。

### 检查更新

启动时自动检查（每天最多一次，可关闭），也可以在菜单里手动检查。发现新版本时可以选择：
- **下载并安装**：自动下载、替换 App 并重启（App 所在目录需要可写，例如「应用程序」）
- 查看发布页 / 跳过此版本 / 稍后

## 从源码构建

```sh
swift build                 # 全部（macOS）
swift test                  # 单元测试；PondCore 的测试在 Linux 上也能跑
swift run KoiPond           # 直接运行（不含屏保组件）
scripts/bundle.sh 0.1.0     # 打包 dist/KoiPond-0.1.0.zip 和 dist/KoiPond-Saver-0.1.0.zip
```

代码结构：

| 模块 | 内容 |
|---|---|
| `PondCore` | 纯 Swift：生物行为、脊柱物理、鱼饵、涟漪、配置、版本比较。不依赖苹果界面框架 |
| `PondRender` | Metal 字符网格渲染（Core Text 预绘字形贴图，一次实例化绘制整屏）和可交互的 `PondView` |
| `KoiPond` | App：窗口、桌面壁纸、菜单栏、配置面板（SwiftUI）、检查更新 |
| `PondSaver` | 屏幕保护程序（动态库，打包为 `.saver`） |

## 发布新版本

1. 在 `CHANGELOG.md` 顶部加一节 `## vX.Y.Z`。
2. `git tag vX.Y.Z && git push origin vX.Y.Z`。
3. GitHub Actions 会在 macOS 上编译、测试、打包，并创建带安装包的 Release；App 里的「检查更新」读的就是它。带 `-` 的版本号（如 `v0.2.0-beta.1`）会发成预发布版本。
